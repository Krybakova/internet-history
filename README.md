# NetHistory — История развития интернета

**Live-сайт:** [https://krybakova.github.io/internet-history/](https://krybakova.github.io/internet-history/)

## Описание проекта

Учебный проект по дисциплине «Технологии Интернет». Тематический сайт, посвящённый истории развития интернета — от первых идей XIX века до современности.

Сайт состоит из 8 связанных страниц:
- **Главная** — общая информация и хронология.
- **1830–1960** — предыстория: телеграф, первые компьютеры.
- **ARPANET** — первая компьютерная сеть.
- **TCP/IP** — протоколы, на которых работает интернет.
- **WWW** — Всемирная паутина.
- **WEB 1.0** — эпоха статичного веба.
- **WEB 2.0** — соцсети и интерактивность.
- **Современность** — мобильный интернет, IoT, облака.

## Используемые технологии

- **HTML5** — семантическая разметка (`<header>`, `<main>`, `<aside>`, `<footer>`, `<figure>`, `<table>`).
- **CSS3** — кастомные стили, анимации (`transition`, `@keyframes`, `transform`), адаптивная вёрстка через `@media`.
- **UIkit 3** — CSS-фреймворк (навигация, бургер-меню Offcanvas, адаптивные классы).
- **JavaScript** — кнопка «Наверх» с плавной прокруткой.
- **Git + GitHub Pages** — контроль версий и хостинг.

## Инструкция по запуску

### Локальный запуск

1. Скачать репозиторий: `git clone https://github.com/Krybakova/internet-history.git`
2. Открыть файл `index.html` в браузере.
3. Готово — сайт работает локально.

Открыть [https://krybakova.github.io/internet-history/](https://krybakova.github.io/internet-history/) в браузере.
